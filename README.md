# CareerCompass AI

CareerCompass AI is an intelligent resume analysis and career recommendation
system designed to help users understand their career opportunities based on
their resume, skills, career readiness, and current job-market information.

## Features

- User Registration and Login
- JWT Authentication
- Resume Upload
- Resume Text Extraction
- Skill Extraction
- ATS Analysis
- Career Prediction
- Skill Gap Analysis
- Career Readiness Assessment
- Personalized Learning Roadmap
- Job Recommendations
- Job Description Analysis
- Resume Improvement Suggestions
- Career-Specific Resume Rewriting
- PDF/DOCX Resume Generation
- Live Job Market Analysis

## Technology Stack

### Frontend
- React.js
- JavaScript
- Axios
- React Router
- CSS/Tailwind CSS

### Backend
- Python
- FastAPI
- SQLAlchemy
- Pydantic
- JWT Authentication
- Passlib/Bcrypt

### Database
- SQLAlchemy-based database layer

### External API
- Adzuna Job Search API
